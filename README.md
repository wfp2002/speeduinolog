# Speeduino Log

Para versao online do projeto acesse: [Speeduino Log Viewer Online](https://wfp2002.github.io/speeduinolog)

Para que o Log funcione corretamente mude para o formato ASCII conforme a imagem abaixo no TunerStudio.

![Formato do Log como ASCII](log-format.png)

Apos gerar o arquivo no tunerStudio, o mesmo sera criado na pasta DataLogs do projeto com a extensao .msl, entao é só abrir esse arquivo no Speeduino Log Viewer, clicando no botao "Escolher Arquivo".

![Screenshot](speeduino-logviewer.png)
